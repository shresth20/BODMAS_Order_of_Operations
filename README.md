# Skill- MT06A01_L01_S07 BODMAS — Order of Operations (Grade 6)

An interactive maths mini-game that teaches the **BODMAS rule** for solving
complex arithmetic — deciding what to calculate first when an expression mixes
brackets, multiplication, addition, and subtraction.

## What it's about

Students move through six short levels, each one building on the last:

1. **× before +** — multiply before you add
2. **× before −** — multiply before you subtract
3. **Mixed operations** — putting the rules together
4. **Multiplication labs** — work bigger products step by step
5. **More practice** — apply the order of operations
6. **Brackets first** — solve what's inside the brackets before anything else

Each level mixes friendly explanations, hands-on activities (tap, drag, type),
instant feedback, voice narration, and a quick celebration when you get it
right — ending with a short summary of how you did.

## Features

- Play in **6 languages**: English, Hindi, Marathi, Telugu, Gujarati, Odia.
- Works fully **offline** — no internet needed once loaded.
- Built for **classroom tablets and interactive panels**, with touch and mouse
  support and a tap/drag hint to guide younger learners.
- Sound effects and spoken narration, plus a "How to Play" guide.

## Play it

It's just a web page — no installation. Start a local server and open it:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000/index.html`.
